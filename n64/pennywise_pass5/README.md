# Pennywise64 PASS5

Corrected-scale Tiny3D N64 sewer slice with a genuine skinned humanoid Pennywise derivative, layered antique-clown costume geometry, a real first-person slingshot model, boss gate, delta-time movement and an exact-ROM Gopher64 smoke test.

PASS5 build validation now applies glTF node transforms when checking sewer world bounds and explicitly parents costume meshes to the armature for skin export.
